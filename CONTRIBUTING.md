# Contributing to Scout

Thank you for your interest in contributing to Scout. This document explains
how to contribute and the terms under which contributions are accepted.

## How to contribute

1. Fork the repository and create a feature branch.
2. Make your changes, including tests where applicable.
3. Ensure your code follows the existing style and passes any checks.
4. Open a pull request with a clear description of the change.

## Reporting issues

Please use the issue tracker to report bugs or request features. Do not
include secrets, credentials, or confidential information in issues or
pull requests.
